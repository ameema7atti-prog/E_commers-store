# E-Commerce Store Application 🛒

A full-stack e-commerce web application built using the MERN stack architecture for **Project 1** of **Task 4** in the **Syntecxhub Web Development Internship**[cite: 46, 50]. This application includes user authentication, dynamic product listings, a shopping cart, a secure checkout process, and a fully functional admin dashboard[cite: 50].

## 🚀 Features
* **User Authentication & Authorization:** Secure login system using JWT authorization and role-based access[cite: 50].
* **Product Listings & Cart:** Browse products by category, add items to a shopping cart, and manage quantities[cite: 50].
* **Checkout & Order Management:** Smooth checkout functionality that records customer orders and updates tracking status[cite: 50].
* **Admin Dashboard:** Dedicated admin portal to add new products, delete existing inventory, and monitor customer orders[cite: 50].

## 🛠️ Tech Stack
* **Frontend:** React.js, HTML5, CSS3[cite: 50]
* **Backend:** Node.js, Express.js[cite: 50]
* **Database:** MongoDB[cite: 50]
